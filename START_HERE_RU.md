# Что подготовлено

Это два учебных примера исправления ошибок для первого портфолио. Они созданы с помощью ИИ; это не выполненные заказы и не оплаченные задачи.

- **Python:** исправлен отбор событий по местной дате. Учтены часовые пояса, границы суток и переходы на летнее/зимнее время.
- **JavaScript:** исправлена сборка параметров URL. Сохраняются `0`, `false`, пустые строки и несколько значений одного фильтра.
- В каждом примере есть исходная версия, исправленная версия, описание, тесты и `fix.patch`.

Проверка: открыть терминал в этой папке и выполнить `python3 scripts/verify.py`. Нужны Python 3.11+, Node.js 20+ и база часовых поясов IANA. Установка сторонних пакетов не требуется.

На исходной версии намеренно проваливаются 7 тестов Python и 5 тестов JavaScript. На исправленной проходят все 19 тестов. Подробности находятся в папке `verification`.

Файл `README.md` и описания примеров написаны по-английски для просмотра потенциальными заказчиками. Публикация этого портфолио сама по себе не приносит оплату: для заработка нужен отдельный согласованный заказ.
